# コンテナ学習教材本文設計

## 目的

既存の VitePress 骨組みに、Linux コンテナの仕組みを初学者向けに段階的に理解できる教材本文を実装する。

## 完成物

- 第1章から第10章までの本文
- 確認問題
- 解答と解説
- ミニプロジェクト
- 次に読む資料

## 方針

- Linux の仕組みを主語に説明する
- ただし Docker 利用者が理解しやすいよう、各章で Docker と結びつける
- 用語を飛ばさず、単語レベルの説明から積み上げる
- 章ごとに `なぜ必要か` から始める
- 図解が必要な箇所は Mermaid を使う
- 実験は Ubuntu Server 上で安全に試せるものに限定する
- 危険な手順や環境依存は明示する

## 章構成ルール

各章は、必要に応じて以下の順で構成する。

1. なぜこの仕組みが必要か
2. 基本概念
3. Docker / コンテナとの関係
4. 図解
5. Ubuntu 実験
6. よくある誤解
7. この章で理解すべきこと

## 内容上の重点

- `process` と `/proc` を足場にする
- `syscall` を user space と kernel space の橋として理解させる
- `namespace` は「見える世界を分ける」
- `cgroup` は「使える資源を制限する」
- `rootfs` は「見える / の中身」
- `mount` は「ファイルシステムを接続する」
- `capability` は「root 権限を分解する」
- `seccomp` は「使える syscall を制限する」
- `OCI runtime` は、これらを組み合わせてコンテナを起動する実行役として説明する

## 実験方針

- `sudo` を使う実験は必要最小限
- `unshare` は観察中心で使う
- `mount` 実験は一時ディレクトリ配下で完結させる
- `systemd-run` は環境依存で動かない可能性を明示する
- `capsh` や `getpcaps` は未導入の可能性を明記する

## 補助ページ方針

- `questions.md` は問題だけ置く
- `answers.md` は各問題の解答例と解説を詳しく置く
- `mini-project.md` は安全重視の簡易コンテナ体験にする
- `next-steps.md` は公式資料、実験の次の一歩、`runc` / `youki` の読む場所を示す
